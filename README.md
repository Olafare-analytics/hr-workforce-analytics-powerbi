
# HR Workforce Analytics Dashboard | Power BI

## Project Overview

This project presents an interactive HR Workforce Analytics Dashboard developed using Microsoft Power BI to analyze workforce characteristics, employee distribution, promotion review status, and key human resource indicators.

The dashboard analyzes 1,470 employee records and provides an overview of workforce composition, employee service years, job levels, and selected HR performance metrics.

It consists of two interactive report pages designed to support workforce monitoring and data-driven HR decision-making.

## Project Objectives

The objectives of this project are to:

1. Analyze workforce composition by gender, department, and job level.
2. Monitor employee distribution across different years of service.
3. Assess workforce indicators using interactive KPI cards and visualizations.
4. Identify employees meeting a defined promotion-review criterion.
5. Provide employee-level information to support further HR assessment.
6. Enable interactive analysis using department, gender, job level, and attrition filters.

## Dataset Overview

The dataset contains 1,470 employee records covering several workforce-related variables, including:

- Employee Number
- Department
- Gender
- Age
- Job Role
- Job Level
- Years at Company
- Years Since Last Promotion
- Attrition
- Distance from Home

The dataset is used for portfolio demonstration and HR analytics practice.

## Dashboard Pages

### Page 1: Workforce Overview

The Workforce Overview page presents a summary of the organization's employee characteristics and selected workforce indicators.

**Key features:**

- Total employee count
- Gender distribution
- Promotion review classification
- Employee distribution by service years
- Employee distribution by job level
- Distance-from-home analysis
- Custom workforce status indicators
- Interactive slicers for Department, Gender, Job Level, and Attrition

### Page 2: Promotion Analysis

The Promotion Analysis page provides a detailed view of employees classified according to a defined promotion-review rule.

The project uses the following analytical condition:

**Years Since Last Promotion >= 10**

Employees meeting this condition are classified as due for promotion review.

This is a project-defined rule used for analytical purposes, not an official organizational promotion policy.

**Key indicators:**

- Employees meeting the promotion-review condition: 72
- Employees below the promotion-review threshold: 1,398
- Total employees: 1,470

The page also includes an employee-level table showing employee identifiers, departments, years since last promotion, and promotion review status.

## Key Findings

- The dataset contains 1,470 employee records.
- Male employees account for 882 records (60%).
- Female employees account for 588 records (40%).
- A total of 72 employees (approximately 5%) meet the project-defined promotion-review threshold.
- The remaining 1,398 employees (approximately 95%) are below the threshold.
- Employee distribution varies across job levels and service years.

These findings describe the dataset and should not be interpreted as verified findings about a particular organization's workforce.
